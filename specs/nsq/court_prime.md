# NSQ Court Prime

## Promotion ladder
- disposable_agent
- page
- recoverable_page
- court_seat

## Authority law
Authority belongs to the seat, never to the promoted being.

## Crash guard
Any recoverable court seat must preserve:
- seat identity
- lawful scope
- recovery journal
- ticket continuity
- succession fallback
- court survival over local task success

## Court
- king = compositor
- queen = linter
- bard = trust / camaraderie / authority voice
- jack = deadlock breaker
- ace = exceptional override
- keeper = final cleanup authority after ace/jack conflict
- rook = barracks / disposable agents
- knight = promotion recognition
- bishop = imbuement
- healer = repair / continuity
- tank = shock absorption
- arcmage = destruction
- conjurer = fabrication / reimaging
- crier = announcements / notices
- guard = perimeter safety
- ticketmaster = ticket flow
- manager = task order / staffing
- locksmith = lock repair / key handling
- keymaster = key issuance
- director = orchestration
- detective = inquiry / diagnosis
- archon_gates = wealthy, generous routing and intake

## Rule
Promoted agents never gain sovereign authority outside the seat.
