# NSQ Density + Sophistication + Parallel v1

## Goal
Scale NSQ by:
- increasing corpus density
- increasing optimizer sophistication
- increasing compile/proof concurrency
- making calibration lock a real consumed surface

## Density
Generation should deliberately create:
- repeated relation families
- repeated symbol clusters
- anchor bands
- membrane state corridors
- calibration families

## Sophistication
Optimizer should:
- threshold macro promotion
- cluster relation families
- cluster target families
- compute more meaningful profile scores
- produce recommendation surfaces from corpus shape

## Parallelization
Runner should:
- compose/lint/optimize/calibrate serially
- compile/inspect/proof branches in parallel after lock generation

## Lock Consumption
Compiler should:
- read calibration lock json
- emit compile manifest
- record selected profile
- record promoted macros
- record representation lock
- not mutate the lock
