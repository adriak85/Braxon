# NSQ Braxon Model Downloader App

The downloader app is a court-owned route, not a music app and not a separate task system.

Canonical path:

NSQ downloader carrier -> NSQ Court route -> model payload materialization -> verification -> NSQ recode gate.

Payload verification is not NSQ recode. A model download is not a whole-core runtime claim.

The downloader rejects Git LFS pointer stubs and only treats safetensors files as materialized payloads when they are real payload-sized files and not pointer text.

The app also records shard reconstruction patterns so enough section pattern data can be carried forward to rebuild expected model sections on site.
