# Repo Reality Benchmark Doctrine V3

## Core principle
The benchmark compares real operator value on the same problem.
It does not force both systems into the same internal method.

## Fairness
Fairness means:
- same task
- same success obligations
- same scoring contract at verdict level
- native strengths fully allowed
- no sabotage
- no flattening
- no compensatory handicapping

Fairness does NOT mean:
- forcing NSQ to behave like C
- removing NSQ substrate advantages
- ignoring reduced debugging burden
- ignoring reduced cross-system friction
- ignoring artifact reuse and replay stability

## Shared task
A damaged but still-usable repository must be understood well enough
to support operator action.

Each system must support answers for:
- what components exist
- what entrypoints matter
- what relationships matter
- what findings matter
- what corruption matters
- what next actions matter
- whether replay is deterministic

## Scoring domains

### 1. Operator truth
- symbol quality
- entrypoint quality
- findings quality
- dependency quality
- call relationship quality
- briefing usefulness

### 2. Native execution value
- elapsed execution
- implementation drag
- operator friction
- adapter burden
- replay stability
- corruption survival
- null output rate

### 3. Substrate value
- reusable artifact quality
- compactness
- semantic density
- queryability
- transformability
- stability across reruns

## Explicit rule for NSQ
If NSQ can solve part of the task through a stronger substrate-native path,
that is a fair advantage and must be counted.

## Explicit rule for C
If C can solve part of the task faster or more directly through native low-level execution,
that is a fair advantage and must be counted.

## Verdict form
The final verdict must report winners for:
- raw speed
- operator usefulness
- deterministic replay
- substrate reuse
- corruption survival
- lowest engineering drag
- best overall base for continued world-building

## Guiding question
Which base leaves the operator spending less time debugging glue
and more time building the world?
