# NSQ Benchmark Intent

This file is bench-spec documentation only.

It must never be:
- printed by runtime commands
- included in timed benchmark output
- embedded into artifacts
- surfaced by doctor/status/repl paths
- counted as generated output
- shown during normal runtime operation

Intent:
Benchmark NSQ as a native substrate-producing base.

Count as real strengths:
- compactness
- replayability
- delayed decode
- structure density
- relation density
- artifact reuse
- future queryability
- transformability
- corruption survival
- reduced operator glue burden

Do not flatten NSQ into C-shaped parity.
