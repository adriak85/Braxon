=== classification ===
A. If a small shard record is only a Git-LFS pointer with no reconstruction route:
   classify as inert pointer stub.

B. If a small shard record is named in a reconstruction manifest, bus file, seed pack, wake packet, stamp registry, or materialization recipe:
   classify as reconstruction handle, not inert pointer.

C. If a stamp says:
   stamp_is_full_payload=false
   stamp_is_wake_trigger=true
   stamp_is_address_anchor=true
   wake_packet_required=true
   materialization_path_required=true
   then the stamp is not supposed to be the payload.
   It is supposed to wake the stored operation/framework at an address.

D. If runtime route execution is not proven:
   do not claim hot-live.
   claim reconstruction route candidate / manifest-bound / bus-bound, depending on evidence.

E. If route execution is proven:
   hot-live proof must name the executable route, input seed/handle, output materialized state, validation digest, and moral/identity invariant preservation.
