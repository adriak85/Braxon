# NSQ Vector Imprint

## Purpose

Vector imprint provides retrieval and semantic recall support for Braxon.
It is derived support, not canonical truth.

## Inputs

- knowledge graph nodes and edges
- canonical artifact tags
- court observer traces
- stack-surface registry descriptors

## Rules

- vector imprint never overwrites canonical knowledge
- embeddings are disposable and regenerable
- lookup results must resolve back to canonical graph nodes or preserved artifacts
- boundary exports may use vector imprint for recall, but they may not redefine NSQ
