# WoWaS Final Canon Control Bundle v8 Addendum

This addendum updates the v7 Braxon-ready set with three hard requirements now locked:

1. **Rolzen knows Pip's mastery long before the world does.**
   He knows because he has personally witnessed the private, uncurated truth of Pip's work: the technical extremity, the emotional certainty, and the way Pip empties himself into sonomancy when he believes no one is meant to hear him.

2. **The travel corridors must carry more adventure and more threat.**
   Travel may not relax into connective tissue. Each corridor has to feel inhabited, dangerous, consequential, and worth surviving. Encounters should combine route pressure, terrain pressure, visibility pressure, and moral pressure instead of reading as decorative combat.

3. **Monster generation now matches the scale of the character system.**
   This bundle adds a monster-species registry sized to the current working character lattice count target used in this edition pass, with every species treated as a reusable monster species rather than a one-off creature sketch.

## Monster law

- Use the same pressure-translation logic as the character generator.
- Start from **American flora, fauna, insects, arachnids, arthropods, microbes, fungi, fish, reptiles, amphibians, birds, mammals, and stones**.
- Give each species **2–4 source-media pressures**, never as direct copies, always translated through WoWaS-native consequence.
- Keep American/common naming first, with neo-scientific naming second.
- Make corridor counties do the heavy lifting:
  - Oklahoma City / Canadian / Cleveland return and launch lanes
  - Rockies abduction band
  - Independence and Oregon coast return
  - Idaho brochure proof corridor
  - Rolla / Onondaga cave siege
  - Mississippi retreat and crater-return ordeal
  - East Coast harvest-front memory lanes

## Threat law

Every significant fight should feel edge-of-seat because the hostile field is doing more than one thing at once:

- **terrain sabotage**
- **visibility distortion**
- **route denial**
- **mob coordination**
- **attrition and exhaustion**
- **moral or rescue pressure**
- **species interactions that change mid-fight**

Do not let monsters become flavor. They must be able to:
- wound the party badly,
- split the party,
- endanger civilians,
- destroy shelter,
- force detours,
- convert wonder into danger,
- or make a correct choice still cost something.

## Adventure law

The corridors should now support:
- rescue pushes,
- hold-the-line stands,
- running fights,
- ambush reversals,
- omen hunts,
- siege hours,
- pursuit through unstable terrain,
- and delayed-payoff ecological threats that return later.
