# NSQ Sees All

## Purpose
Sees All notices before broad runtime awareness forms.

## Duties
- detect anomaly onset
- surface pre-failure pressure
- mark semantic drift before rupture
- emit heads-up toward linter
- emit forewarning toward picker
- notify bard, guard, detective, and crier

## Constraint
Sees All observes and warns.
Sees All does not convict, punish, or seize unrelated authority.

## Outputs
- linter_heads_up
- picker_heads_up
- court_heads_up
- anomaly_forewarning
- horizon_notice
