# NSQ ASM Operating Law

## Core Rule

ASM is now the operating law for NSQ execution, recode, and optimization.

This does not mean NSQ becomes ASM.

This does not mean NSQ becomes binary.

The correct authority chain is:

    NSQ canonical source truth
      -> ASM operating / recode / optimization form
      -> Braxon binary translation output when Braxon is ready to emit it

## What ASM Does

ASM is the operating surface that lets NSQ place, optimize, and execute incoming translated material with enough exactness for Braxon to use later.

ASM should be used for:

- recoding incoming source surfaces
- optimizing NSQ-operable instructions
- creating a machine-near operating form
- preserving source lineage and metadata impact
- preparing Braxon to emit binary translations

## What ASM Does Not Do

ASM does not become the identity of NSQ.

ASM does not outrank NSQ.

ASM does not turn NSQ into a wrapper, byte language, overlay, or binary frontend.

ASM does not override the personal moral invariant.

## What Binary Does

Binary is a downstream Braxon translation product.

Braxon may switch ASM operating forms into binary translations after NSQ authority and ASM operating validation are satisfied.

Binary output must preserve lineage back to:

1. original source
2. NSQ authority law
3. ASM operating form
4. validation proof
5. moral invariant preservation check

Binary is not the source truth.

## Repository Honesty Rule

The repository must not pretend Braxon is live, finished, or complete merely because metadata, ASM carriers, or translation rules exist.

The correct status is:

    Braxon is being made runnable.
    NSQ authority is being clarified.
    ASM operating law is being installed.
    Binary translation is the downstream target.

## Moral-Invariant Boundary

The personal moral invariant is not a goal file.

Goals can be reviewed, prioritized, aligned, and rewritten.

The moral invariant does not change toward harm.

No code file, metadata file, ASM recode, generated report, binary translation, future tool, or downstream file may reinterpret the moral invariant into a contrary value.

All translations must preserve the moral invariant's value.
