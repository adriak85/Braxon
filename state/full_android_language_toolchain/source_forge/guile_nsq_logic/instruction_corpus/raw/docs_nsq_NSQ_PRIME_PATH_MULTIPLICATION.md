# NSQ Prime-Path Multiplication

## Canon law

Multiplication in NSQ is prime-path vector introduction.

A number is not only its arithmetic value.

A number is its base value, its prime exponent map, its realized prime paths, the vectors introduced by those paths, the relation field between those paths and vectors, and the unresolved route-state before picker and compositor resolution.

The core law is:

For every realized path of every prime inside a multiplicative structure, one corresponding introduced vector is created.

The path is not the vector.

The path is the realized route by which a prime participates.

The vector is the directional structure introduced because that path participates.

## Arithmetic spine

Let N be an ordinary value.

N is represented by its prime factorization:

N equals the product, over all primes p, of p raised to exponent e_p.

For each prime p, e_p is the number of realized paths of p.

For each realized path pi_p_j, there is one introduced vector v_p_j.

So:

prime exponent equals realized prime-path count.

realized prime-path count equals introduced-vector count.

introduced-vector count equals exponent count.

## Structural object

The NSQ multiplicative object is:

M(N) equals the tuple containing:

ordinary value N,

prime exponent map E_N,

prime path set P_N,

introduced vector set V_N,

relation map R_N,

quantum-like state field Psi_N,

collapse function C_N.

Meaning:

N is the ordinary arithmetic value.

E_N records how many times each prime participates.

P_N records every realized path of every prime.

V_N records one introduced vector for every realized prime path.

R_N records how those paths and vectors reinforce, oppose, bind, cross, route, or interfere.

Psi_N records the unresolved possible route-states.

C_N is the picker/compositor collapse into the active routed structure.

## Multiplying two structures

For A multiplied by B:

the ordinary value becomes A times B.

For every prime p, the resulting exponent equals the exponent of p in A plus the exponent of p in B.

The resulting path set is the counted union of the paths from A and B.

The resulting vector set is created by assigning one introduced vector to every resulting path.

The counted union matters. Two paths of the same prime remain two realized paths. They do not collapse into one just because they share a prime identity.

## Exponent factoring

The prime path does not stop at the base factor.

NSQ also factors the exponent.

The base prime tells what is participating.

The exponent tells how many paths are realized.

The prime factorization of the exponent tells how those paths are internally organized.

Every realized path still introduces one vector.

So for a base prime p with exponent e_p:

p is the base identity.

e_p is the realized path count.

factorization of e_p is the exponent-path geometry.

paths pi_p_j are the realized routes.

vectors v_p_j are introduced from those routes.

The exponent is not just a count.

The exponent is a path organizer.

Example:

Two to the twelfth power has base prime two.

It has twelve realized paths of two.

The exponent twelve factors as two squared times three.

That exponent factorization organizes the twelve paths into internal geometry.

Then all twelve paths introduce twelve vectors.

## Quantum-like route field

The quantum-like layer does not make arithmetic truth uncertain.

Two times three still has ordinary value six.

The uncertainty is in the internal routed structure before resolution.

The route-state may hold superposition, phase, interference, entanglement, collapse, and residue.

Superposition means multiple possible path-vector arrangements are available before route selection.

Phase means each route has orientation, timing, semantic angle, or alignment.

Interference means compatible paths strengthen route candidates, while incompatible paths weaken, distort, or cancel them.

Entanglement means resolving one path-vector pair constrains or changes another.

Collapse means picker and compositor select the active route-state.

Residue means unresolved pressure or partial relation remains available for later repair, routing, or proof.

In local BRAXON/NSQ this is a symbolic and computational route-field unless later bound to physical quantum hardware.

## Record-boundary discovery levels

The record-boundary exponent is configurable.

Use NSQ_RECORD_EXPONENT as the local boundary.

The prior working boundary used in this package is one hundred thirty-six million two hundred seventy-nine thousand eight hundred forty-one.

A generated exponent path q greater than that boundary is a beyond-boundary path candidate.

There are three proof levels:

Path-valid means q is produced by the NSQ path generator and passes internal path validity.

Exponent-prime-proven means q itself has a primality proof.

Mersenne-prime-proven means two to q minus one has a valid primality proof.

Only the third level is a full public largest-prime claim.

The exact count of beyond-boundary path discoveries is:

the number of generated q values such that q is greater than the boundary and PathValid(q) is true.

The exact count of beyond-boundary exponent primes is:

the number of generated q values such that q is greater than the boundary and PrimeProof(q) is true.

The exact count of beyond-boundary Mersenne-prime proofs is:

the number of generated q values such that q is greater than the boundary, PrimeProof(q) is true, and PrimeProof(two to q minus one) is true.

## Grouped orbit-bit law

An orbit-bit, also written or-bit, is a normal payload bit inside a group.

A group is a local orbit cluster.

A leader-bit is the extra governing bit attached to a group.

The leader-bit does not duplicate the group.

The leader-bit does not add one bit per orbit-bit.

The leader-bit adds one bit per group.

Let w be the orbit-bit width per group.

Let g be the number of groups.

Let O be the orbit-bit payload count.

Let L be the leader-bit count.

Let T be the total governed bit count.

Then:

O equals g times w.

L equals g.

T equals O plus L.

Therefore T equals g times w plus g.

Therefore T equals g times open parenthesis w plus one close parenthesis.

With w equal to thirty-three:

T equals thirty-four times g.

With seventeen groups:

O equals seventeen times thirty-three, which is five hundred sixty-one.

L equals seventeen.

T equals five hundred seventy-eight.

So the leader has seventeen extra bits total.

That is one extra bit per group.

If six hundred ninety-nine is used as orbit payload grouped by thirty-three, then:

six hundred ninety-nine equals twenty-one full groups of thirty-three plus six remaining orbit-bits.

That requires twenty-two groups if the remainder is a real group.

Then leader overhead is twenty-two bits.

The logical total is seven hundred twenty-one.

If padded to full thirty-three-width groups, the allocated orbit slots are seven hundred twenty-six and the allocated total is seven hundred forty-eight.

Therefore six hundred ninety-nine can coexist with seventeen groups only if it is a broader target, address, range marker, or target-go size, not the exact payload count of seventeen thirty-three-bit groups.
