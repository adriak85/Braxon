# Monster Count Alignment v8

## Count target used
- Monster species generated in this supplement: **319**
- County anchors covered: **16**
- Hard encounter templates generated: **96**

## Why this count
This pass was sized to the current working character-lattice scale used in the Braxon-ready edition pass so the monster ecology no longer feels undersupplied next to the people, factions, and route pressures.

## Coverage emphasis
The monsters are weighted hardest toward:
- Rockies abduction band
- Oregon coast return and Independence corridor
- Idaho brochure proof corridor
- Rolla / Onondaga shell arc
- Mississippi retreat and crater-return ordeal
- Oklahoma return lanes
- East Coast harvest-front references

## Design rule
Each monster species is built as a reusable species-level pressure source, not a one-scene novelty.
