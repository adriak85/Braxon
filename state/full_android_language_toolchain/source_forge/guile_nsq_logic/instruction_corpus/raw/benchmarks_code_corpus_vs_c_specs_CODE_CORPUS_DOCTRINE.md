# Code Corpus Benchmark Doctrine

## Core question
Which base handles deep structured coding data better as human-readable information?

## Benchmark shape
The corpus is code-shaped and systemic:
- lexical layer
- structural layer
- relational layer
- system layer

## Corpus challenge classes
- small
- medium
- large
- stress

## Challenge features
- nested scopes
- repeated symbols
- shadowing
- imports
- calls
- branches
- loops
- comments/doc blocks
- cross-file references
- partial corruption slices

## Primary score
- information_per_second

## Supporting scores
- readable_lines_per_second
- structural_nodes_per_second
- relation_edges_per_second
- deterministic_repeat_match
- corruption_survival_rate
- null_output_rate

## Fairness
- same generated corpus
- same timing discipline
- native strengths allowed
- no sabotage
- no artificial parity inflation
