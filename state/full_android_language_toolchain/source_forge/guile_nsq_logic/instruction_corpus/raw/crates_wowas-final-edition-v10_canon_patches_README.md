# WoWaS Patch Folder Status After v13

This folder is preserved.
It is not dead.
It is not trash.
It is not safe to forget.

But after the v13 authority consolidation, it is no longer supposed to act as the first place Braxon goes to learn current WoWaS truth.

## New role of this folder
This folder now exists as:
- provenance
- migration history
- audit trail
- subordinate support during direct tree rewrite

The primary authority entrypoint is now:
- `../wowas_final_authority_system_v13.md`

The patch absorption registry is:
- `../wowas_patch_absorption_registry_v13.md`

## Operating rule
Do not make runtime depend on replaying the patch stack forever.

Read patches when you need to:
- verify where a rule came from
- inspect migration history
- audit whether a tree rewrite kept a truth intact
- pull detailed subordinate support from TSV lanes

Do not treat this folder as the main control bundle anymore.

## What changed
Before v13, the patch folder still carried too much active truth burden.

After v13:
- the operative control layer was merged upward into one authority surface
- the patch folder was demoted to provenance and support
- the remaining debt became tree-rewrite debt, not patch-selection confusion

## What still belongs here
Keep:
- patch notes
- migration manifests
- old prose / authority / quality instructions
- detailed TSV support lanes
- anything useful for audit and reconstruction

## What should happen next
The next major pass should rewrite the scene tree directly so the truth lives inside the per-scene and per-book files.

That means:
- scene connectors embedded in scene files
- obligation tracking embedded in scene files
- cast presence embedded in scene files
- generated-character insertion decisions embedded in scene files
- image coverage embedded in scene files
- derived indexes regenerated from rewritten scene truth

When that rewrite is complete, this folder remains valuable for provenance, but it should not be necessary to replay it just to know what WoWaS is.
