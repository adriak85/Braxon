# Information Per Second Benchmark Doctrine

## Core question
Is the base better at producing useful human-readable information?

## Primary score
- information_per_second

## Definition
Information is calculated from human-readable output.

## Primary measurable forms
- readable_output_bytes
- readable_output_lines
- readable_semantic_units

## Supporting scores
- determinism
- failure discipline
- replay integrity
- representation burden

## Fairness
- same input burden
- same timing discipline
- both systems may use native strengths
- no sabotage
- no fake parity inflation

## Important rule
Raw bytes are not the main score.
Human-readable output is the main score.
