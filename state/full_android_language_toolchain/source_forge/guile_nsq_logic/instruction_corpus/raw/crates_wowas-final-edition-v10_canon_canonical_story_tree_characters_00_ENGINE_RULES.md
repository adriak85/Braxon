# WoWaS Character Generator — Engine Rules (Locked)

## Core rules from pasted_text canon update

1. **Structural salvage rule**: Use the arc-engine machinery (scene packet logic, world-state, orbital tracking, population layering) but spread across the REAL 25-book spine. Never collapse to a one-book frame.

2. **Pip age lock**: Pip is an adult male, ~25. NOT 15. Age-15 data is bad branch. Discard.

3. **Population target**: ~2 million background characters. Most never named in books but have lives, places, routines, pressures, social ties. World must support lived experience and believable memory.

4. **Source-hero engine**: Parse required roles/functions. Generate each character from 2–4 source heroes depending on power/importance.

5. **Source reuse rule**: Every source hero reused at least 3 times, NEVER the same way.

6. **Moral inversion rule**: ~1/3 of strong positive source material used in evil or morally mixed characters. Evil chars always have a real good side. Do not flatten morality.

7. **Source record richness**: Source entries carry: name, franchise, function harvested, emotional/narrative traits, backstory value, light side, shadow side, relationship style, power style, what must NOT be copied literally.
