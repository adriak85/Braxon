# WoWaS Final Edition Braxon-Ready Bundle v8

This bundle carries forward the full v7 Braxon-ready set and adds the monster/adventure/threat supplement requested afterward.

## New in v8
- **319 monster species** focused on actual travel counties and major biomes
- **96 corridor encounter templates** built for edge-of-seat fights
- expanded county pressure map including Mississippi retreat and East Coast harvest fronts
- control addendum locking the mastery line and threat/adventure law

## Core use order
1. Read `wowas_final_canon_control_bundle_v7.md`
2. Read `wowas_final_canon_control_bundle_v8_addendum.md`
3. Load the scene / lattice / orbit files from v7
4. Apply `wowas_corridor_encounter_pressure_patch_v8.tsv`
5. Apply `wowas_monster_species_registry_v8.tsv` and `wowas_county_corridor_pressure_map_v2.tsv`
