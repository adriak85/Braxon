# NSQ Derived Artifacts

Derived artifacts are allowed for:
- machine compatibility
- storage
- indexing
- export
- transport
- benchmarking

They are not canonical NSQ truth.

## Examples

- packed binary transport
- adjacency indexes
- symbol interning tables
- macro interning tables
- benchmark fixtures
- wire frames
- derived lane classes
- compatibility exports

## Rule

If an artifact lowers native NSQ into machine-lane assumptions, it must be named and treated as derived.
