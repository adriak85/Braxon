# Eight-Dimensional Gradient

The eight-dimensional gradient is not the same thing as the brain, spine, metadata, watermark, court, or NSQ itself.

Keep these distinct:
- eight-dimensional gradient
- brain
- singular spine
- watermark
- metadata
- systems
- court/compositor
- NSQ substrate

The gradient is a state/intent/semantic-pressure system. It must not be collapsed into a flat scoring table or ordinary metadata tag list.

The current target is octillion-scale state expressivity through NSQ/Braxon state composition, not through ordinary bit-packing claims.

Implementation must preserve:
- base-8 semantics
- charge-aware interpretation
- lever-resolution behavior
- semantic intent weighting
- positive and negative variable presence
- proof/accounting boundaries
- no fake ceilings
