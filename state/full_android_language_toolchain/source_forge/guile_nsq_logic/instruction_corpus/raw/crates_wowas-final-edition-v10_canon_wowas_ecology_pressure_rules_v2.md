# WoWaS Ecology Pressure Rules v2

This file extends the overwrite-ready scene / lattice / orbit baseline with corridor-county ecology law.

## Locked ecology law
- Use the same source-pressure harvest method as the character generator.
- Each creature, plant, fungus, microbe, or stone-form should merge **at least 2 source-media pressure traits**, usually 3, from different source families.
- Keep the American ecological anchor first: start with real American flora, fauna, insects, arachnids, arthropods, microbes, or stones.
- Reimagine final naming into American/common + scientific-feeling WoWaS names, not direct IP names.
- Source-media names remain generator-side only so the translation rules stay traceable.
- Include American mythic pressure and microbiology pressure where they make the world more concrete, dangerous, or beautiful.

## County law
- For the Oregon / Idaho / Missouri / Oklahoma corridors, use county as the cohesion unit.
- Each county gets a pressure theme, myth register, microbiology register, and a coherent creature cluster.
- Wildlife is not decorative. A county’s creatures should make travel through that county feel distinct.
- If a county’s pressure is wonder-from-wreckage, local life should build livability or reveal beauty.
- If a county’s pressure is fear-by-stripping, local life should remove shelter, certainty, coherence, or safe approach.
- Transitional counties should produce mixed fields where beauty and danger are bound together.

## Naming rule
Use this pattern:
- prose/common name: evocative American-facing field name
- neo-scientific name: genus-root + altered epithet that reads like field taxonomy, not parody

## Placement rule
Do not insert wildlife just to decorate.
Insert it where it does at least one of these:
1. makes daily life in Whispers of Willow and Stone more concrete
2. creates a memorable hazard or resource economy
3. reveals how a county or biome thinks/feels after the Diamond breaks
4. mirrors or complicates a character pressure line
5. creates wonder, dread, or unstable attraction the cast must react to
