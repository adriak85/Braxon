# Braxon Ready Manifest v8 Addendum

This addendum extends the v7 Braxon-ready pack with the missing monster/adventure/threat layer.

## Added operative files
- `wowas_monster_species_registry_v8.tsv` — 319 monster species
- `wowas_corridor_encounter_pressure_patch_v8.tsv` — 96 encounter templates
- `wowas_county_corridor_pressure_map_v2.tsv` — expanded county focus map
- `wowas_final_canon_control_bundle_v8_addendum.md`
- `wowas_monster_count_alignment_v8.md`

## Intended use
Load v7 first as the base canon/control package.
Then apply v8 as the ecology, travel-threat, and adventure-density supplement.

## Purpose
This closes the underpowered-travel gap:
- stronger corridor identity
- more dangerous mobs and monster species
- more edge-of-seat encounters
- better alignment between character-system scale and ecological threat scale
