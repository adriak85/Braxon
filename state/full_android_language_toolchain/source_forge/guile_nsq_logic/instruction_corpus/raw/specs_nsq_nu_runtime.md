# NSQ Native Runtime (`nu`) Specification

## Purpose

`nu*` names denote NSQ-native runtime classes and court-visible semantic surfaces.

They are not aliases for conventional unsigned machine integers.

## Current floor

- switch domain: 0 or 1
- lever domain: 1..1126
- paired structure: switch/lever alternating
- first semantic cell: language / operating surface declaration
- following cells: symbol, macro, algorithmic expression, or later approved semantic roles

## Native family

- `nu_anchor`
- `nu_lever`
- `nu_cell`
- `nu_word`
- `nu_surface`
- `nu_court_route`

These names indicate NSQ-native semantic grades, not inherited CPU-width truth.

## Mapping rule

- canonical floor truth lives in `nu*`
- machine/export storage may use foreign carriers at the boundary
- machine/export storage must never define NSQ meaning

## Practical interpretation

A canonical NSQ cell is not "an integer lane".
It is a validated semantic unit carrying switch/lever structure and role.
