# NSQ Language-Master Surfaces

## Purpose

Language-master surfaces hold projection and translation knowledge for foreign stacks.
They are native Braxon surfaces, not detachable plugins.

## Responsibilities

- define how a foreign stack surface maps into preserved NSQ semantics
- define how canonical NSQ projects back out to that foreign surface when needed
- define surface-specific court routing requirements
- define observer and knowledge-graph touchpoints

## Separation rule

- language-master surfaces are not the knowledge graph
- language-master surfaces are not the vector imprint
- language-master surfaces are not the runtime watcher
- language-master surfaces are not the foreign boundary bundles themselves

They inform those layers while remaining distinct from them.
