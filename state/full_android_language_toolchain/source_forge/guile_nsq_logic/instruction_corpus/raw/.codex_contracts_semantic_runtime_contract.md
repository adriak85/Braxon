# Semantic Runtime Contract

Braxon runtime surfaces must not falsely claim more than they prove.

Console may speak through verified state only when the reply is marked non-canned and state-generated.

Python ingress records calls. It does not become a Python runtime.

Host OS handover emits a release response. It does not power off unless explicitly requested and validated.

Materialization may be:
- manifest-bound
- external boundary
- materialized
- hot-live verified

Never collapse these states.
