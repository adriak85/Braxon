# NSQ Knowledge Graph

## Purpose

The knowledge graph is the canonical structured knowledge and state layer for Braxon.
It is not the observer, not the vector imprint, and not the court itself.

## Core node families

- canonical surface
- court component
- stack surface
- language master
- boundary projection
- runtime observer event
- proof artifact
- calibration lock

## Core edge families

- routes_to
- projects_to
- derives_from
- watches
- calibrates
- preserves
- proves

## Truth source

The knowledge graph is fed from:
- canonical NSQ artifacts
- court outputs
- runtime watcher observations
- approved stack-surface registry entries

It must not be rebuilt from foreign export bundles alone.
