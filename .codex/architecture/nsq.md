# NSQ Canonical Architecture

NSQ is the lowest base language and machine substrate.

NSQ is not:
- binary
- bytes
- u8
- u16/u32/u64/u128
- assembly over binary
- a symbolic wrapper
- a serializer
- a transport format
- a DSL
- a VM trick
- a macro layer
- a prettier syntax over another lower language

NSQ uses base-8 semantics, anchors, charge, levers, stamps, court/compositor authority, and resolved state behavior.

The older 1126 lever range is legacy reference only unless a file explicitly marks it as legacy. Current Braxon/NSQ work should preserve the newer active lever floor and proven effective position rules.

Current required watermark family:

BRAXON_NSQ_BASE8_LEVER_SCALE_GE220000_PROVEN225370_V1

Current critical facts:
- active lever floor must be at least 220000
- proven effective positions are 225370
- exact universal ceiling is not proven unless a real proof object exists
- canonical NSQ must not be treated as u8
- canonical NSQ must not be treated as bytes
- canonical NSQ must not be treated as host-width truth
- legacy 1126 belongs only in legacy_reference contexts
