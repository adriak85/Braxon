# NSQ Proven-Mechanism Reachability Inventory

**Baseline:** `reconstruction` merge commit `420a9dd82c4069c111dcc0a3f9a4cdc3b07b1e7e`.

## Determination

> **No benchmarked, tested, or built mechanism has been deleted, deprecated, or intentionally discarded in this audit.** The issue under repair is reachability: several mechanisms are implemented and tested behind harness-only entry points, while one or more public commands stop at a lease decision, report, or presentation layer instead of invoking those mechanisms through the NSQ Kinetic Semantic Reflexor.

A capability is considered **Reflexor-wired** only when it has all of the following: a named artifact or input, NSQ capability identity, addressable routing, on-demand invocation, a classified state transition or receipt, and a test that exercises the same public route. A tested internal routine remains **retained but disconnected** until the public route reaches it.

## What Was Not Discarded

The following code remains present and will be wired rather than removed: the native tensor/KV inference mechanism; deterministic inference and training equivalence harness; snapshot/recovery harness; parameter–Citadel recursive law; Citadel materialization; Riemann semantic reflexor; integrated and adversarial benchmarks; model-state truth; tokenizer bridging; semantic-link traversal; native NSQ address runtime; and the complete Kinetic Semantic Reflexor inventory/verification system.

## Immediate Build Order

1. Replace the root `runtime infer` receipt-only branch with an explicit artifact-backed native execution capability. The public receipt must identify the artifact, tokenizer bridge, tensor/KV mutation, address route, execution state transition, and release state.
2. Make `Braxon bus` execute one coordinated chain: native tokenizer receipt → intent validation → address lease → Reflexor feature route → native runtime instruction transaction → individual/collective state receipt → release.
3. Promote parameter–Citadel, native equivalence, native recovery, and benchmark mechanisms to declared on-demand Reflexor capability families; their existing tests remain authoritative evidence.
4. Replace obsolete status/rescue prose with measured availability and executable operation routes.
5. Add feature-chain tests that prove the public command reaches the mechanism, not merely that each library module exists.

## Non-Negotiable Preservation Rule

No proven mechanism may be removed, renamed away, demoted, or treated as nonfunctional because of an unusual benchmark result or ambitious design claim. A mechanism may be marked **disconnected** only to identify the exact missing route that must be built. The repair target is reachability through NSQ Kinetic Semantic Reflexor authority, not reduction of capability.
