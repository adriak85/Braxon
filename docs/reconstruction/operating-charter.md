# Braxon / NSQ Reconstruction Operating Charter

Status: working reconstruction charter; not a claim of runtime completion.

## Objective

Recover the system's best current representation by recursively reconciling current implementation, historical branches, WOWAS/source-of-truth artifacts, architecture contracts, and later revisions. Preserve intent and behavioral invariants rather than blindly preserving obsolete implementation forms.

## Construction model

The preferred native construction path is:

`source/history -> intent extraction -> intent gradient -> canonical NSQ coordinate -> semantic/causal tree -> Citadel formation -> parameter/state materialization -> universal synchronized tokenizer -> cognitive poles -> NSQ bus -> observation/action -> reality comparison -> discrepancy -> reconstruction`

A seed is considered successful only when it can generate the logical structures required for execution without secretly requiring a monolithic preinstalled copy of the final intelligence.

## Intelligence model

The six cognitive poles remain the brain. The four sensory bodies extend the Council rather than replacing it. The universal tokenizer provides a shared semantic identity with section-specific projections and a universal composition layer. Logical parameter completeness is distinct from physical residency: a Citadel may represent a complete logical parameter domain while only an active region is materialized on the bus.

## Evidence rules

Never treat a stale document as authoritative over newer implementation without reconciliation. Never treat a newer implementation as correct merely because it is newer if an older invariant was lost. Distinguish designed, implemented, built, integrated, executed, and verified. A deterministic scaffold is not native cognition unless the actual causal path reaches executable intelligence.

## Recursive convergence

For every candidate mechanism:

1. Locate current implementation.
2. Locate historical/alternate implementations.
3. Locate WOWAS and architecture contracts.
4. Compare chronology and dependencies.
5. Classify as current, superseded, regression, missing, or intentionally retired.
6. Preserve the strongest surviving invariant.
7. Map the required intent into NSQ-native form where appropriate.
8. Add tests/invariants for the behavioral claim.
9. Re-run the comparison against predicted convergence.
10. Repeat until remaining differences are explained.

## Validation target

The eventual runtime validation must reach the actual seed -> Citadel -> tokenizer -> cognitive poles -> bus -> response path. Only after that path executes should the system be evaluated through persistent generated worlds, including the requested real-world and Whispers/Stone world variants. World quality must be assessed by coherence, continuity, causal consistency, entity persistence, novelty, and correspondence between imagined and observed state—not prose quality alone.

## Current boundary

Source-level reconstruction is substantially advanced, including historical Citadel/ten-pole/seed-reconstruction machinery. Native execution of the complete reconstructed brain remains an execution-environment-dependent verification step and must not be falsely reported as completed until actually run.
