# ⁰ Odyssey

## Title Reading Law

The full written series title is:

**⁰ Odyssey**

The leading mark **⁰** is not spoken aloud.

The title is read aloud simply as:

**Odyssey**

The leading **⁰** means **nullsquared**.

This mark is part of the written identity of the series, but it is silent in ordinary speech.

## Machine Identity

For Braxon, repo metadata, file-safe identifiers, registry references, and tooling paths, the machine-safe identity is:

`nullsquared_odyssey`

The display title remains:

`⁰ Odyssey`

The spoken title remains:

`Odyssey`

The silent prefix remains:

`⁰`

The silent prefix meaning remains:

`nullsquared`

## Canon Rule

When older files, tools, metadata, or conversations refer to **Whispers of Willow and Stone** as the series, Braxon should interpret that as an older naming state.

Arc 01: **Whispers of Willow and Stone**

Existing WoWaS canon remains valid unless a separate canon rule says otherwise.

## Filename Safety Rule

Use **⁰ Odyssey** in reader-facing display contexts.

Use `nullsquared_odyssey` in filenames, paths, package IDs, registry IDs, JSON keys, NSQ identifiers, and tooling references.

This avoids Unicode normalization problems while preserving the correct title.
