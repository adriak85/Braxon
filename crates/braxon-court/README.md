# Braxon-court

`Braxon-court` reads the generated Braxon court configuration and prints an operator-facing summary of offices, escalation policy, and kingdom laws. It is a projection surface for configured court state, not the final native court runtime.

## Responsibilities
- load `config/braxon_court.json`
- summarize office count, required ledgers, and escalation chain
- surface current law toggles such as crash guarding and inheritance rules
- print every configured office with title, class, and authority domain

## Command
```bash
cargo run -p Braxon-court --release --
```

## Inputs and outputs
- Input: `config/braxon_court.json`
- Output: newline-delimited status lines for office and law review

## Workspace links
- Consumes artifacts generated by `Braxon-kingdom-generate`
- Sits beside `nsq-court` as the Braxon-facing court summary tool
