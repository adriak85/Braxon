# WoWaS Book Dialogue Seed Registry v10

## Purpose
This registry gives Braxon explicit manuscript-bearing dialogue and play targets for each book so expansion does not stop at beat summary, "tone and structure lock," or scaffold repetition.

Use with:
- `patches/PROSE_AND_TONE_GUIDE.json`
- `patches/v10/wowas_prose_and_tone_patch_v10.md`
- `patches/v10/wowas_dialogue_and_play_insertion_patch_v10.md`

## Global rules
- These are insertion targets, not compressed summaries.
- Each item should become one or more real scenes, usually dialogue-led.
- Prefer lived interaction over narrated explanation.
- Prefer joy, curiosity, domesticity, and moral-pressure truth where canon allows.
- Normalize Boojay-era references forward into Rylos where the older label still exists in source material.

## Lock rule
When a chapter has only scaffold language like:
- "tone and structure lock"
- "the book finds its law"
- repeated reconstruction fillers

the generator must search this registry first for the strongest matching dialogue/play insertion target before defaulting to connective summary.

## Outcome rule
A completed manuscript pass should read like these people truly lived through the canon, loved inside it, and kept finding joy without betraying the scale of the suffering.
